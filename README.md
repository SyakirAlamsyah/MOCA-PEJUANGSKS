# MOCA - Edge AI Lab Safety System with NVIDIA Jetson Nano

MOCA adalah sebuah sistem pemantauan Keselamatan dan Kesehatan Kerja (K3) cerdas berbasis **Edge Computing** yang dirancang untuk mencegah kecelakaan di lingkungan laboratorium secara *real-time*. MOCA mengintegrasikan algoritma deteksi objek **YOLOv8** dan logika sekuensial **Finite State Machine (FSM)** untuk mengevaluasi kelengkapan Alat Pelindung Diri (APD) dan perilaku berisiko.
